Privacy Policy

Last updated: FEBRUARY 2026

1. General information

This application is an independently developed arcade-style video game. It does not require user registration, account creation, or the submission of personal data.

The developer is committed to protecting user privacy and complying with Regulation (EU) 2016/679 (General Data Protection Regulation – GDPR).

---

2. Data collected by the application

The application does not collect personally identifiable information.

The following data is stored exclusively on the user's device:

  • Game scores and play times
  • Unlocked medals and achievements
  • Cosmetic items obtained (e.g. skins)
  • Game settings and preferences

This data:

  • Is not sent to external servers
  • Is not shared with third parties
  • Is not accessible to the developer
---

3. Advertising

The application displays non-personalized advertisements provided by third-party services, such as Google AdMob.

These services may collect limited technical information, including:

  • Device type
  • System language
  • Approximate country or region
  • Technical data related to ad performance

This information is used solely for ad delivery and measurement purposes. The developer does not create advertising profiles or track users individually.

For more information about how Google processes data, please refer to their Privacy Policy:

https://policies.google.com/privacy

---

4. Content sharing feature

The application includes an optional feature that allows users to share their game score via external applications, such as WhatsApp.

This action:

  • Is initiated exclusively by the user
  • Does not involve the collection of personal data
  • Does not transmit information to the developer
---

5. Offline usage

The application can be used without an internet connection.

An internet connection is only required to display advertisements. If no connection is available, ads will simply not be shown.

---

6. Children

This application is not specifically directed at children under the age of 13 and does not contain inappropriate content.

No personal data from minors is knowingly collected.

The developer reserves the right to modify this Privacy Policy. Any changes will be published on this page.
